# Artifact Schemas (qnnbench)

All runs generated by `qnnbench` write self-contained artifacts to `runs/<run_id>/`.
The identifier `run_id` is a 12-character SHA1 hex digest uniquely derived from the canonical representation of `RunKey`.

---

## 1. `trace.csv`
Records metrics per optimization step and evaluation checkpoint.

| Column | Type | Description |
|---|---|---|
| `run_id` | str | 12-char hex identifier |
| `update` | int | 0-indexed update step number |
| `circuits_train` | int | Cumulative circuit executions charged to training |
| `shots_train` | int | Cumulative shots charged to training |
| `shots_monitor` | int | Cumulative shots charged to validation/monitoring |
| `shots_pilot` | int | Cumulative shots charged to pilot probes |
| `wall_s` | float | Elapsed wall-clock seconds since start of run |
| `train_mse` | float | Current training loss estimate |
| `val_mse` | float | Validation set mean squared error |
| `val_acc` | float | Validation set classification accuracy in $[0, 1]$ |
| `grad_norm` | float | Euclidean norm of evaluated parameter gradient |
| `step_norm` | float | Euclidean norm of parameter update delta ($\|\theta_{t+1} - \theta_t\|$) |
| `lr_eff` | float | Effective learning rate at current step |
| `spsa_a_t` | float | SPSA step-size scaling factor $a_t$ (NaN if not SPSA) |
| `spsa_c_t` | float | SPSA perturbation scaling factor $c_t$ (NaN if not SPSA) |
| `qng_damping` | float | Fubini-Study damping factor $\lambda$ (NaN if not QNG) |
| `qng_cond` | float | Condition number of $(G + \lambda I)$ (NaN if not QNG) |
| `qng_fallback` | bool | True if fallback policy was triggered on this step |
| `clipped_val` | int | Count of validation feature entries clipped to $[0, \pi]$ |
| `clipped_test` | int | Count of test feature entries clipped to $[0, \pi]$ |
| `track` | str | Experiment track (`main`, `historical`, `noise`) |

## 2. `events.jsonl`
Append-only log of granular budget and device events.

```json
{
  "seq": 1,
  "run_id": "a1b2c3d4e5f6",
  "category": "training",
  "tag": "psr_update",
  "circuits": 330,
  "shots_per_circuit": 32,
  "shots_total": 10560,
  "update": 1,
  "wall_s": 0.082
}
```

Categories:
- `training`: Charged to training budget.
- `monitoring`: Charged to monitoring budget.
- `pilot`: Charged to pilot budget in adaptive allocation.
- `search`: Charged during hyperparameter selection.
- `reference`: Free analytic checks, uncharged.

## 4. `arrays.npz`
Binary numerical trajectories:
- `theta_history`: Array of shape `(n_steps + 1, 17)` containing parameter flat vectors.
- `grad_history`: Array of shape `(n_steps, 17)` containing gradient flat vectors.
- `spsa_deltas`: Array of perturbation directions for SPSA runs.
- `metric_cond_history`: Condition number trajectory for QNG runs.

---

## 5. `config.yaml`
Full resolved configuration used for the run, containing base parameters, optimizer parameters, budget constraints, and seeds.

---

## 6. `env.json`
Host execution environment metadata:
- `python_version`
- `numpy_version`
- `scipy_version`
- `pennylane_version`
- `platform`
- `cpu_count`
- `git_commit`
